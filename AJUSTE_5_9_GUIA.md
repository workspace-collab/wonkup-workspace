# Ajuste 5.9 - Selector compacto de color en notas

## Cambio

El detalle de la nota deja de mostrar seis tarjetas de colores. Ahora utiliza el mismo patrón visual que **Color de marca** en el formulario de proyecto:

- un selector nativo de color;
- una muestra compacta;
- el código hexadecimal visible;
- actualización inmediata del código;
- soporte para cualquier color hexadecimal;
- contraste automático del texto del post-it.

Los colores rápidos que aparecen al pasar el mouse sobre el post-it se mantienen. Al elegir uno de esos colores se elimina el color personalizado y se aplica el preset correspondiente.

## Instalación

Sube el contenido del ZIP de cambios a la raíz del repositorio y reemplaza los archivos. Usa el commit:

```text
Ajuste 5.9: selector compacto de color en notas
```

Después del despliegue, cierra la pestaña anterior, vuelve a abrir GitHub Pages y realiza una recarga forzada. El editor debe mostrar `Motor 5.9.0`.
