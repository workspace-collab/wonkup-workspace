# Guía de actualización — Entrega 2

## Opción recomendada

1. Descarga y descomprime el paquete de la Entrega 2.
2. Abre tu repositorio `wonkup-workspace` en GitHub.
3. Selecciona **Add file → Upload files**.
4. Arrastra el contenido de la carpeta, no la carpeta externa.
5. GitHub reemplazará los archivos modificados y añadirá los nuevos.
6. Usa el commit: `Entrega 2: accesos, roles y workspaces`.
7. Abre GitHub Pages y prueba los cinco códigos del README.

## Importante

La plataforma inicia en modo `mock`. No configures Apps Script hasta comprobar que todos los perfiles funcionan visualmente.
